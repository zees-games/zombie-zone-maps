# Zombie Zone's tier of the converter's rules

Read by dot-map's `bsp.py regen --game-rules tools/convert` over the addon's defaults. A table here (`textures.tsv`, `models.tsv`, `sounds.tsv`, `classes.tsv`, `free_textures.tsv`; formats in dot-map's `dotbsp/rules.py`) overrides a default row by key; a map's own facts go in `maps/<id>.json`. Empty tables are on purpose: the defaults answer until a coverage report shows a zombie-specific gap.
